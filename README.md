# Лабораторные работы по хранилищам данных

Вариант 14 из 15: 44-й студент по списку, `(44 - 1) % 15 + 1 = 14`.
Предметная область: учет выдачи фильмов в видеопрокате.

| Папка | Содержание |
| --- | --- |
| `Лаб 1` | PostgreSQL 3НФ, Data Vault, документная MongoDB и шесть отчетов |
| `Лаб 2` | Локальный Git и удаленный репозиторий GitHub |
| `Лаб 3` | Основные операции MongoDB по выданному заданию |
| `Лаб 4` | Neo4j: 1000 узлов выдач и запросы Cypher |

Файлы `Отчет.pdf` в каждой папке предназначены для сдачи. SQL, JavaScript и
Cypher содержат воспроизводимые исходники. Исходные файлы преподавателя и
локальные журналы выполнения исключены из Git.

## Запуск из PowerShell

Нужны Git, Docker Desktop и работающий Docker Engine. Все обращения к базам
выполняются через CLI внутри контейнеров. Из корня проекта:

```powershell
./run-labs.ps1
```

Скрипт поднимет PostgreSQL, MongoDB и Neo4j, загрузит данные и выполнит
контрольные запросы. Повторный запуск пересоздает только учебные схемы и базы
в контейнерах проекта. Имя Compose проекта фиксировано как `video-labs`, так
как кириллическое имя каталога не подходит для автоматического имени Compose.

Локальные адреса: PostgreSQL `127.0.0.1:55432`, MongoDB
`127.0.0.1:57017`, Neo4j Browser `http://127.0.0.1:57474` и Bolt
`127.0.0.1:57687`. Пароли в `compose.yaml` предназначены только для локальной
учебной среды. Остановить контейнеры: `docker compose -p video-labs down`.

Репозиторий хранит синтетические данные, не персональные сведения.
